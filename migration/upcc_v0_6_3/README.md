# Immutable UPCC donor evidence

This directory is reserved for the **Universal Project Control Center v0.6.3 / B003R3** donor snapshot used by CTX-PROJOPS migration work.

## Rules

1. Donor files are evidence, not active Cortex runtime source.
2. Never edit files under `donor/` after import.
3. Never add donor PowerShell/runtime files to the Cortex Cargo workspace or invoke them as Cortex internals.
4. Port behavior deliberately into typed Cortex authorities and retain provenance back to donor paths/hashes.
5. PCC remains independently runnable and remains the project-operations execution authority.
6. Re-import requires explicit `-Force` and produces a new manifest; do not silently mutate donor evidence.

`DONOR_MANIFEST.json` is generated by `scripts/Import-UpccDonor.ps1`.
